# Examples and Routing Tests

- `api_request_examples.jsonl`: representative Unity-to-router requests.
- `api_response_examples.jsonl`: representative model structured outputs.
- `routing_test_cases.jsonl`: small regression set covering broad/specific routing, contextual ASR correction, ambiguity, multi-question control, and final decisions.

The confidence values shown in examples are illustrative, not calibrated probabilities.
